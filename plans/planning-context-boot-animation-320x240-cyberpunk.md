# 320×240 开机动画原型规划上下文

## 上下文摘要

- 用户目标是在仓库内直接产出一份 **320×240 嵌入式小屏** 的开机动画 HTML 高保真原型。
- 视觉风格明确为 **赛博朋克风**，需体现霓虹紫 / 蓝 / 青、辉光、扫描线、网格、启动脉冲、加载状态等元素。
- planning 已确认主交付物应为 **HTML 原型**，而不是优先走 Figma → LVGL 转换链路。
- 正式产物应写入 `docs/prd-boot-animation/hifi-wireframes/`，规划中间产物写入 `plans/`。

## 识别意图

- 本次任务本质是一次 **高保真原型设计与落地**。
- 用户希望得到的是可以直接在浏览器中打开预览的静态 HTML 原型，而非需求文档、架构方案或代码框架。
- 输出重点是小尺寸屏幕适配、风格一致性与启动动画氛围营造。

## 推荐路由

- 推荐执行路径：**designer Agent → prototype-design Skill**
- 生成方式：**方式 A（直接写 HTML/CSS/JS）**
- 设计方向：
  - 固定画布：`320×240`
  - 风格：赛博朋克 / 科技启动界面
  - 交互：品牌标识 + 扫描脉冲 + 进度反馈 + 状态文案

## 开放问题

- 品牌名称未被用户指定，需要在原型中使用占位品牌文案。
- 未提供现成 PRD / wireframe 页面，因此本次按“单页开机动画原型”直接落地。
- 未指定是否需要导出为 LVGL 结构，本次仅交付 HTML 原型与导航页。

## 执行建议

1. 在 `docs/prd-boot-animation/hifi-wireframes/` 下创建单页开机动画原型。
2. 使用统一主题变量定义赛博朋克配色，保证页面与导航页视觉语言一致。
3. 将动画控制在纯 HTML/CSS/JS 范围内，保证文件双击即可预览。
4. 在导航页中标注尺寸、风格与入口链接，便于后续评审和扩展。
